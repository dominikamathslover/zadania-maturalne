# Generator zestawów zadań maturalnych

Projekt aplikacji internetowej umożliwiającej tworzenie własnych zestawów zadań maturalnych z matematyki. Użytkownik może wybierać zadania według dostępnych kryteriów, losować zadania oraz eksportować przygotowany zestaw do pliku PDF.

## Funkcjonalności

- Wybieranie zadań maturalnych z dostępnej bazy.
- Filtrowanie zadań według wybranych kryteriów.
- Losowanie zadań do zestawu.
- Wyświetlanie wybranych zadań na stronie.
- Eksport gotowego zestawu zadań do pliku PDF.

## Technologie

- **React** – tworzenie interfejsu użytkownika.
- **JavaScript** – logika aplikacji.
- **HTML** – struktura strony.
- **CSS** – wygląd i stylowanie.
- **html2pdf.js** – eksport zawartości strony do pliku PDF.

## Cel projektu

Celem projektu jest stworzenie prostego i wygodnego narzędzia do samodzielnego przygotowywania zestawów zadań maturalnych. Aplikacja ma ułatwiać powtarzanie materiału, ćwiczenie wybranych zagadnień oraz przygotowywanie zestawów do samodzielnej nauki.
